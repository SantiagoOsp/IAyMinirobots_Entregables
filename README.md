# Inteligencia Artificial y Minirobots — Entregables

Este repositorio reúne los entregables teóricos y prácticos del curso **Inteligencia Artificial y Minirobots**. Su propósito es organizar las actividades académicas y documentar el trabajo desarrollado a lo largo del curso, desde el estudio de los fundamentos de la inteligencia artificial hasta sus aplicaciones y los modelos generativos.

Las entregas se presentan mediante documentos y archivos de trabajo, agrupados por tarea. Esta organización permite consultar cada actividad de forma independiente y mantener una referencia del proceso de aprendizaje.

## Contenido académico

Los entregables reúnen las respuestas y desarrollos de las actividades propuestas durante el curso. Los documentos presentan el análisis teórico y las explicaciones de cada actividad; los archivos de código y notebooks, cuando forman parte de una entrega, documentan los procedimientos, ejemplos y resultados correspondientes.

Cada tarea conserva sus propios archivos y contexto. El README principal funciona como presentación e índice del repositorio, mientras que las explicaciones particulares se encuentran dentro de cada entrega.

## Propósito del repositorio

El repositorio conserva los entregables del curso en una estructura identificable por tarea. Los archivos permiten revisar las respuestas, seguir el razonamiento de los desarrollos y consultar la evidencia documentada en cada actividad.
